# Brüche, Gleichungen, Terme und Variablen

Lernangebot zur Vorbereitung auf eine Klassenarbeit mit Brüchen, Gleichungen, Termen und Variablen.

## Schnellstart

1. Repository herunterladen oder klonen.
2. `index.html` in einem aktuellen Browser öffnen.

## Dokumentation

- [Projektüberblick, Dateiaufbau, Entwicklung und Pflege](./docs/README.md)

## Änderungen prüfen

Rechenwege, Aufgaben und Rückmeldungen fachlich prüfen und nach Änderungen im Browser testen. Offene Punkte werden in der [Pflegedokumentation](./docs/README.md#pflege-und-offene-aufgaben) erfasst.
