# Dokumentation: Mathe_Br-che_Gleichungen_Terme

## Aktueller Stand

Der Repository-Name deutet auf Mathe-Inhalte, aber die aktuelle index.html ist ein Wunschzettel- und Bestellformular der Innovativ AG. Sie entspricht aktuell dem HTML-Stand im Repository [InnovativAG](https://github.com/Jubitwo/InnovativAG). Deshalb dokumentiert diese Seite zunächst den vorhandenen Inhalt und kennzeichnet die Diskrepanz, statt nicht vorhandene Mathe-Lerninhalte zu beschreiben.

## Bestehender Inhalt

Das Formular bietet Anfragearten für Taschenrechner, Gravuren, Lehrkräfte, Klassen/Gruppen und eigene Vorschläge. Es erfasst optionale Angaben zur Person, Kontaktangaben, Anfragebeschreibung und bei Bedarf Menge, Termin oder Gravurtext. Vor dem Absenden ist eine Zustimmung zur Übermittlung vorgesehen; außerdem kann ein vorbereiteter Text kopiert werden.
