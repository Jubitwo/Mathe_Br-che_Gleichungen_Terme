# Dokumentation: Brüche, Gleichungen, Terme und Variablen

## Projektüberblick

Lernangebot zur Vorbereitung auf eine Klassenarbeit mit Brüchen, Gleichungen, Termen und Variablen.

## Architektur und Dateiaufbau

- `index.html` – Einstiegspunkt des browserbasierten Lernangebots.

## Entwicklung und Prüfung

1. `index.html` in einem aktuellen Browser öffnen.
2. Aufgaben und Rechenwege vollständig durchspielen.
3. Fachliche Ergebnisse, Hinweise und Rückmeldungen prüfen.
4. Darstellung und Bedienbarkeit auf schmalen Bildschirmen kontrollieren.

## Pflege und offene Aufgaben

Neue Arbeit als GitHub-Issue mit Ziel, betroffenen Themen, erwartetem Ergebnis und Prüfschritten erfassen.

### Pflege-Checkliste

- [ ] Aufgaben fachlich korrekt und eindeutig
- [ ] Rechenwege und Erklärungen verständlich
- [ ] Rückmeldungen bei typischen Fehlern geprüft
- [ ] Änderungen im Browser getestet
- [ ] README und Dokumentation aktualisiert
